# PRD v1 – אפליקציה ללימוד זמן לילדים

## 1. מטרת המוצר

פיתוח אפליקציה אינטראקטיבית לילדים בגילאי **7–9**, שמטרתה ללמד הבנת זמן באופן הדרגתי, חווייתי ומותאם ליכולת הילד.

המוצר אינו מיועד רק ללימוד קריאת שעון, אלא להבנת המשמעות של זמן בחיי היום־יום.

האפליקציה תשלב:

- שעון אנלוגי
- שעון דיגיטלי
- הבנת שעות ודקות
- חלקי היום
- זמן יחסי
- פעילויות מחיי היום־יום
- יצירת פעילויות אישיות על ידי הילד
- תרגול ומשחק
- התאמת רמת קושי אוטומטית
- מעקב התקדמות להורה

---

# 2. מטרת הפרויקט הטכנולוגי

הפרויקט משמש במקביל כתרגיל ללימוד פיתוח אפליקציות באמצעות AI.

הפיתוח יתבצע בגישת:

**Product Owner → GitHub → Codex → Code → Review → Test → Merge → Deploy**

המשתמש אינו נדרש לכתוב קוד.

Codex ישמש כמפתח המרכזי.

מטרת הלמידה הטכנולוגית היא להבין בהדרגה:

- כיצד אפליקציה בנויה
- Frontend
- Components
- State
- API
- Data
- Database
- GitHub
- Branches
- Commits
- Pull Requests
- Testing
- Deployment
- שילוב AI באפליקציה
- ניטור שימוש ועלויות AI
- הקשר ל-FinOps for AI

# 4. עיקרון פדגוגי מרכזי

המערכת תלמד:

> **זמן ולא רק שעון**

הילד צריך לדעת:

1. לזהות מה השעה.
2. להבין את הקשר בין שעון אנלוגי ודיגיטלי.
3. להבין כמה זמן עבר.
4. להבין כמה זמן נשאר.
5. לקשר שעה לפעילות בחיי היום־יום.
6. להבין בוקר / צהריים / אחר הצהריים / ערב / לילה.
7. להבין שאותה שעה בשעון אנלוגי יכולה להתרחש בחלקים שונים של היום.
8. רק בשלב מתקדם יותר להבין את ההבדל בין שעון 12 שעות לשעון 24 שעות.

| חלק ביום | שעות |

בשלב הראשון הילד ילמד את השעה כפי שהיא מופיעה בשעון אנלוגי, יחד עם חלק היום.

**7:00 בבוקר → שבע בבוקר**

**7:00 בערב → שבע בערב**

**10:00 בלילה → עשר בלילה**

המטרה היא להבין כי:

> **7:00 בבוקר ו־7:00 בערב נראות אותו הדבר על שעון אנלוגי, אבל מתרחשות בזמנים שונים ביום.**

# 8. מעבר משעון 12 שעות לשעון 24 שעות

ההבחנה בין **12 שעות ל־24 שעות היא שלב מתקדם**, ולא חלק מהלמידה הראשונית.

## שלב ראשון

הילד מכיר:

**7:00 בבוקר**

לעומת:

**7:00 בערב**

המחוגים בשעון האנלוגי נמצאים באותו מקום.

ההבדל נלמד באמצעות:

- חלק היום
- פעילות
- הקשר

לדוגמה:

**7 בבוקר → מתארגנים לבית הספר**

**7 בערב → ארוחת ערב**

## שלב מתקדם

לאחר שהילד שולט בכך, נלמד את הייצוג הדיגיטלי של 24 שעות:

**7:00 בבוקר → 07:00**

**7:00 בערב → 19:00**

בשלב זה הילד ילמד:

> **07:00 ≠ 19:00**

למרות שבשעון אנלוגי המחוגים נראים זהים.

```text
User
 ↓
UI
 ↓
Frontend
 ↓
Application Logic
 ↓
API
 ↓
Database
 ↓
External Services
 ↓
AI Model
```

ובהמשך להבין גם:

```text
AI Request
 ↓
Prompt
 ↓
Context
 ↓
Tokens
 ↓
Model
 ↓
Response
 ↓
Latency
 ↓
Cost
```
